\begin{abstract}
Experimental nanobody melting-temperature (Tm) data are limited. Computed
stability values can be used during model training, but they describe quantities
related to Tm rather than Tm itself. We compared complete simulation plans and
calculated quantities as additional training targets. We trained multi-task
models that used a shared ESM2 sequence model for experimental Tm and one
computed label at a time. We used 57 Tm labels for training, 114 for validation,
and 396 reserved for final testing. Each label and encoder setting was tuned
separately using only the Tm validation set, then compared using the same test Tm
labels. With a frozen encoder, an MD native-contact label lowered Tm error by
0.20$^\circ$C under a local mutation-scan plan on two fixed structures, compared
with an observed reduction of 0.05$^\circ$C under a heterogeneous structure-panel
plan. These plans also differed in contact selection and trajectory averaging,
so the comparison does not isolate the choice of variants. Free-energy
perturbation (FEP) labels gave the lowest observed error with both frozen and
fine-tuned encoders, lowering the fine-tuned mean absolute error from
6.55$^\circ$C to 6.40$^\circ$C; the 95\% interval for this change included
zero. Native-contact labels gave a clear gain only with the frozen encoder,
while Rosetta and ThermoMPNN scores gave little or no gain. The results suggest
that simulations for experimental prediction should be planned around both the
variants to calculate and the quantity to report, rather than the number of
computed values alone.
\end{abstract}

\begin{keywords}
nanobody thermostability, melting-temperature prediction, multi-task transfer
learning, protein language model, molecular simulation labels
\end{keywords}

\begin{significance}
When experimental melting-temperature data are scarce, computed stability
values may help a prediction model. In this study, a local mutation-scan plan
gave a larger observed reduction in frozen-encoder error than a heterogeneous
structure-panel plan. FEP gave the lowest observed error with both frozen and
fine-tuned models. These observations suggest considering both which variants
to calculate and which physical quantity to report when planning simulations.
\end{significance}
