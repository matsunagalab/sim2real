\section*{Results}

\subsection*{A target-centered framework for using simulation labels in Tm prediction}

We first established an evaluation framework for asking whether
simulation-derived labels improve experimental Tm prediction. The target task
was nanobody Tm regression from sequence. Computational labels were treated as
auxiliary source tasks rather than as substitutes for experimental Tm. Each model
shared an ESM2 sequence encoder between a Tm prediction head and an auxiliary
source-label head, allowing the source task to shape the representation while
keeping the final objective anchored to experimental Tm prediction
(Fig.~\ref{fig:learning_framework}).

The comparison was deliberately target-centered. All candidate settings were
selected using an experimental Tm development set, and the final numbers were
computed only on a held-out experimental Tm test set. Improvements were assessed
by paired differences in absolute error on the same test examples. This design
addresses a common ambiguity in simulation-to-experiment learning: a source task
can be learnable and physically meaningful without improving the target
experimental phenotype.

\subsection*{Auxiliary-label scaling depends on the physical source label}

We next varied the number of experimental and computational labels to determine
whether more source data translated into better Tm prediction. As expected,
increasing the number of experimental Tm labels improved Tm-only performance
(Fig.~\ref{fig:scaling}). FEP mutation free-energy labels also showed a
beneficial trend: the full FEP label set gave the best held-out Tm error among
the FEP label-count settings. The curve was not strictly monotonic, so we do not
interpret it as a clean power law. Instead, we interpret it as evidence that
additional FEP labels can improve the target task when they are selected and
evaluated through the experimental Tm endpoint.

The MD-derived contact-persistence label behaved differently. Increasing the
number of these labels did not yield a robust improvement over Tm-only learning,
even though the source labels were also generated from simulations. Thus, the
label-count experiment already suggested the central result of the paper:
auxiliary data quantity is not sufficient. The transferable physical content of
the source label matters.

\subsection*{FEP mutation free-energy labels provide the strongest final improvement}

We then compared the selected settings for each auxiliary source. Tm-only
training achieved a held-out test MAE of 6.61$^\circ$C. Adding FEP mutation
free-energy labels reduced the MAE to 6.26$^\circ$C, corresponding to a paired
improvement of 0.35$^\circ$C (90\% confidence interval, 0.24--0.46$^\circ$C;
Fig.~\ref{fig:final_performance}). This was the clearest improvement observed
across all source labels.

The other sources showed weaker or negative effects. Rosetta-scored variants
generated by ESM2 improved over Tm-only learning (paired improvement,
0.17$^\circ$C; 90\% confidence interval, 0.03--0.31$^\circ$C), and ThermoMPNN
mutation-effect labels showed a similar but smaller gain. Rosetta mutation
scores and Rosetta-scored random variants were weaker and had confidence
intervals that crossed zero. The MD-derived contact-persistence label worsened
the final test error relative to Tm-only learning. These results support a
selective, source-dependent interpretation: mutation free-energy-like labels
were useful, but a structural trajectory summary was not sufficient for this
target task.

\subsection*{The FEP gain is not explained by encoder size alone}

Because PLM scale can affect downstream performance, we tested whether the
benefit of FEP labels could be reproduced simply by increasing the ESM2 encoder
size. It could not. In the Tm-only setting, larger 35M and 650M encoders did
not improve held-out performance relative to the 8M encoder. In the FEP setting,
the 35M and 650M encoders reached 6.50 and 6.65$^\circ$C MAE, respectively,
both worse than the 8M FEP model. FEP labels remained beneficial within each
size comparison, but the best absolute performance was obtained with the
smallest encoder and FEP auxiliary labels. Thus, in this low-Tm-data regime,
the dominant gain came from the physical source label rather than from scaling
the language model.

\subsection*{Encoder adaptation helps exploit the auxiliary signal}

We also asked whether the FEP gain required updating the sequence encoder. In a
frozen-encoder control, overall errors increased, but FEP still improved over
the frozen Tm-only baseline: the frozen Tm-only model achieved 7.38$^\circ$C
MAE, whereas frozen FEP achieved 7.20$^\circ$C MAE. The improvement was smaller
than in the updated-encoder setting, and the frozen FEP model remained worse
than the updated-encoder FEP model. These results indicate that FEP labels carry
useful information even when the representation is fixed, but limited encoder
adaptation is important for extracting the strongest target-task benefit.

\subsection*{Physics-labeled generated variants connect auxiliary learning to design loops}

Rosetta labels on ESM2-proposed variants improved Tm prediction over the Tm-only
baseline, whereas the comparison between ESM2-proposed and random Rosetta-scored
variants was suggestive but not conclusive. The paired improvement of
ESM2-proposed variants over Tm-only learning was 0.17$^\circ$C (90\% confidence
interval, 0.03--0.31$^\circ$C). By contrast, the paired difference between
ESM2-proposed and random variants was 0.07$^\circ$C in favor of ESM2-proposed
variants, with a confidence interval crossing zero. We therefore interpret this
result conservatively. Physics-labeled generated variants retain useful
supervised signal for Tm prediction, but the present data do not prove that the
current generator is superior to random variant sampling.

\subsection*{Mutation free-energy labels provide a physical interpretation}

The final pattern suggests why FEP labels transfer to Tm prediction even though
they are not Tm measurements. Experimental Tm labels provide sparse anchors for
the absolute thermal-stability phenotype. Mutation free-energy labels provide
local information about how stability changes under sequence perturbations.
When learned jointly, these two views can shape a representation that is more
useful for held-out Tm prediction than either sparse Tm labels alone or a
generic simulation-derived summary. The negative result for the MD-derived
contact-persistence label defines the boundary of this interpretation: a
simulation label must encode the right physical relation to the target phenotype.
