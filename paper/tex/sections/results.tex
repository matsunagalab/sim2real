\section*{Results}

\subsection*{A transfer-learning architecture for using computational labels in Tm prediction}

We used a transfer-learning architecture to incorporate simulation or
physics-based labels into Tm prediction when experimental Tm measurements are
scarce. The target task is Tm prediction, while the computational labels measure
related but non-identical quantities. Models share a sequence encoder between a
Tm prediction head and an auxiliary computational-label head. Model settings
were selected using the experimental development set, and all final claims were
evaluated on the same held-out Tm test examples
(Fig.~\ref{fig:learning_framework}).

\centering
\includegraphics[width=\textwidth]{fig_outline01_concept_protocol}
\caption{\textbf{Transfer-learning architecture for low-data Tm prediction.}
\textbf{(A)} Measured Tm labels define the target task, and computational labels
define source tasks that provide additional supervised signal.
\textbf{(B)} The architecture shares a sequence encoder between the Tm task and
a computational-label task. Model settings are selected using the experimental
development set.
\textbf{(C)} Candidate auxiliary sources include mutation-effect labels,
generated-variant labels, and an MD-derived contact-Q label.
\textbf{(D)} Final comparisons use held-out Tm test errors and paired bootstrap
statistics.}
\label{fig:learning_framework}
\end{figure*}

\subsection*{FEP labels scale differently from structural MD labels}

We next evaluated how prediction accuracy changes as the number of training
labels increases. Experimental Tm labels show the expected low-data scaling.
FEP mutation-effect labels also improved the best held-out Tm MAE as the
auxiliary label set increased, with the full FEP label set giving the best
result. The curve was not perfectly smooth, but its best point separated from
the Tm-only and MD contact-Q curves. In contrast, the MD contact-Q curve did
not provide a robust improvement over Tm-only training (Fig.~\ref{fig:scaling}).
Thus, the gain is not explained by adding more computational labels generically;
it depends on the physical content of the auxiliary label and on allowing the
sequence representation to adapt.

\begin{figure*}[t]
\centering
\includegraphics[width=\textwidth]{fig_outline02_source_screen}
\caption{\textbf{Scaling with experimental and computational labels.}
\textbf{(A)} Tm-only learning improves as more experimental labels are used.
\textbf{(B)} FEP mutation-effect labels give their best held-out Tm error at
the full label set, although the curve is not perfectly smooth.
\textbf{(C)} MD contact-Q labels likewise do not show a robust improvement over
Tm-only training.
\textbf{(D)} Best points from the label-count sweeps separate FEP from the
Tm-only and MD contact-Q references.}
\label{fig:scaling}
\end{figure*}

\subsection*{FEP mutation-effect labels provide the strongest final improvement}

At the selected settings, FEP mutation-effect labels improved held-out Tm
prediction from 6.61 deg C MAE for Tm-only training to 6.26 deg C MAE. The
paired improvement was -0.353 deg C MAE with a 90\% confidence interval from
-0.462 to -0.243 deg C (Fig.~\ref{fig:final_performance}). Other
free-energy-like or generated-variant labels showed weaker but informative
effects, whereas the MD contact-Q label did not improve final Tm prediction
when the encoder was updated. Repeating the core comparison with a frozen
encoder reduced overall accuracy and attenuated the auxiliary-label gains:
FEP still improved over frozen Tm-only training, but the best frozen FEP model
remained substantially worse than the updated-encoder FEP model. Increasing
the ESM2 encoder from 8M to 35M or 650M parameters did not improve this
small-Tm-data setting. With FEP labels, the 35M and 650M encoders reached
6.50 and 6.65 deg C MAE, respectively, both worse than the 8M FEP model.

\subsection*{Physics-labeled generated variants connect the method to design loops}

Rosetta labels on ESM2-proposed variants also improved Tm prediction over the
Tm-only baseline (paired $\Delta$MAE = -0.165 deg C, 90\% CI -0.306 to
-0.025 deg C). The comparison between ESM2-proposed and random Rosetta variants
was suggestive but not resolved by the current data (paired $\Delta$MAE =
-0.065 deg C, 90\% CI -0.195 to +0.064 deg C). We therefore interpret this
result as evidence that physics-labeled generated variants retain a useful Tm
learning signal, not as proof that the current generator outperforms random
sampling.

\subsection*{Mutation-effect labels provide a plausible interpretation of the improvement}

The final interpretation is that Tm and mutation-effect labels provide different
views of stability. Experimental Tm labels anchor the absolute phenotype, while
mutation-effect labels provide local directions in sequence space. This explains
why FEP labels can help without directly measuring Tm. The contrast with MD
contact-Q shows the boundary of this interpretation: a structural persistence
summary is not necessarily a useful auxiliary label for Tm generalization
(Fig.~\ref{fig:interpretation}).

\begin{figure*}[t]

\includegraphics[width=\textwidth]{fig_outline04_mdq_boundary}
\caption{\textbf{Interpretation and boundary condition.}
\textbf{(A)} Tm labels provide sparse absolute anchors, while mutation-effect

\textbf{(B)} FEP improves Tm prediction, whereas MD contact-Q does not.
\textbf{(C)} Contact-Q summarizes retained hydrophilic native contacts in high

\textbf{(D)} The useful signal is not generic simulation augmentation, but

\label{fig:interpretation}
